Blueprint: Variable Rebinder — Community Update

This release is focused on reliability, clearer apply results, and better handling of tricky real-world files.

What’s new

* More reliable apply verification: Variable application is now checked after every apply and retried once before being marked as failed
* Visible failure reporting: Apply failures are surfaced directly in the UI instead of failing silently
* Stronger selection-scope remapping: Single selected layers, instance children, and override nodes are now included more reliably during apply
* Better mixed-text handling: Text segment variable application has improved verification and failure reporting
* Smarter target variable lists: Variable pickers now show unscoped variables plus variables scoped to the selected surface, while hiding incompatible scoped variables
* Clearer numbered variable names: Numeric parts of variable names are now visually highlighted, making names like Neutral 000, Neutral 100, and Neutral 900 easier to compare
* Natural numeric sorting: Target variable lists now sort numbered names in a more human-friendly order
* Unified apply result panel: The UI now shows one clear apply outcome instead of multiple overlapping success messages

Fixes

* Fixed cases where applying a variable appeared to do nothing
* Fixed text-fill target variables with TEXT_FILL scope not appearing when scope metadata had to be resolved from a remote library
* Fixed selection-scope edge cases where a valid selected node could be skipped during apply
* Fixed misleading success messaging when no bindings were actually applied
* Improved resilience when remapping variables on instance-related nodes and overrides

UX improvements

* Apply results now use consistent “applied” terminology
* Skipped bindings are included in the apply summary when relevant
* Pre-apply summary chips stay visible but no longer compete with the main result state after apply
* Variable picker rows now include clearer spacing and path context when searching, so similar variable names are easier to distinguish

Why this matters

This update makes Blueprint much easier to trust on complex design system cleanup work. When something applies, you can see it clearly. When something fails, you can see exactly where and why.

What changed:

Numeric parts of variable names now render as tabular accent chips, so Neutral 000, Neutral 100, 95%, etc. are much easier to scan.
Variable picker rows now have a cleaner two-line layout when context is useful.
Picker sorting is now numeric-aware, so numbered variables order more naturally.
Scanned variable cards also highlight numeric tokens for consistency.
